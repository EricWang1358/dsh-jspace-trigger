# dsh-jspace-trigger

可配置规则触发的 J-Space 轻量 DSH 插件（设计/调研中）。

## 目标

- 不搞一刀切注入；
- 根据可配置规则（关键词/正则/长度/显式命令）判断是否提示加载 `j-space`；
- 未命中时零成本；
- 命中时只做 near-field 轻提醒，不强制注入。
